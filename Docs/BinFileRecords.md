# BIN File Records

This document summarizes generally useful record groups. Exact record indexes and per-screen mappings are intentionally kept out of the public reference because they are asset- and context-specific.

## Indexed UI-Layout Resources

| Resource family | General contents |
| --- | --- |
| Battle command window | Command icons and labels, cursor pieces, list rows, party-selection panels, and related window decoration. |
| Player status window | Character panels, names and portraits, HP/MP rows, gauges, and status-condition indicators. |
| Battle-end results | Result backdrops, experience and stat rows, rank or level notices, and dropped-item panels. |
| Field status menu | Status cards, page backgrounds, selectors, numeric glyphs, equipment and stat labels, and menu icons. |
| Wanted viewer | Poster and viewer layout members paired with container-local texture or model resources. |

These groups describe observed content, not a universal record numbering scheme. Record meaning depends on the specific file and its active material context.

## Other BIN Records

The world-map area table is a separate fixed-record family. Its entry identities are not public until the record schema is sufficiently established.
